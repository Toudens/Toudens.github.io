# Toudens 写作与排版速查

按 2026-11-10 的实现记录。本站使用 Hugo + Hextra，输出静态网页。尺寸单位均为 CSS 像素；浏览器缩放、窗口大小及滚动条会影响实际可用空间。

这份 README 放在项目根目录，不会作为博客文章被收录。日常文章写在 `content/` 下。

## 1. 常用尺寸

主要布局见 [assets/css/navigation.css](assets/css/navigation.css)。

| 项目 | 当前设置 | 写作时如何理解 |
| --- | --- | --- |
| 整站最大宽度 | `1560px` | 超宽屏幕上整体居中，继续拉宽窗口也不会无限增长 |
| 左侧栏预留空间 | `292px` | 正文工作区从此处开始，不等于侧栏外框的实际宽度 |
| 左侧栏外框 | `264px`，即 `292 - 28` | 内部还要扣除边框、内边距和文章树缩进 |
| 右侧目录／更新日志 | `264px` | 修改时还要同步顶栏搜索所在列的宽度 |
| 正文与右侧栏间距 | `24px` | 两个圆角框之间的距离 |
| 页面区左右留白 | 各 `28px` | 在左侧栏预留空间之外，正文工作区内部的留白 |
| 普通正文 `main` 最大宽度 | `880px` | **包含**左右内边距，不是文字可用宽度 |
| 普通正文内边距 | 上 `24px`，左右各 `36px`，下 `40px` | 普通正文理论最大文字宽度约 `808px`：`880 - 72` |
| 旅行影集正文 `main` 最大宽度 | `1100px` | 实际仍受正文框和右侧栏限制，通常达不到这个上限 |
| 首页轮播内容最大宽度 | `880px` | 还受首页主框扣除左右各 `36px` 后的空间限制 |
| 顶栏高度／顶部留白 | `64px`／`12px` | 正文框与顶栏之间另有 `16px` 间距 |
| 全站主要外框圆角 | `14px` | 由 `--site-radius` 控制 |
| 站名字号 | `20px` | 左侧栏顶部的站名 |
| 主栏目／文章树字号 | `16px`／`15px` | 栏目名称与下方文章列表分别设置 |

**普通文章写作以约 570～808px 的正文宽度为参考，不要按整个浏览器宽度排版。**

在右侧栏可见、采用默认布局时，可以这样粗略估算：

```text
S = min(浏览器窗口宽度, 1560)
主框宽度 ≈ S - 左侧预留292 - 页面留白56 - 右侧栏264 - 栏间距24
文字宽度 ≈ min(主框内部宽度, 880) - 正文内边距72
```

下表是估算值，边框和滚动条可能再占少量空间；首页和旅行影集的宽度上限规则与普通文章略有不同。

| 窗口宽度 | 普通文章文字区 | 首页轮播／旅行影集内容区 |
| --- | --- | --- |
| `1280px` | 约 `570px` | 约 `570px` |
| `1440px` | 约 `730px` | 约 `730px` |
| `1560px` 及以上 | 最大约 `808px` | 约 `850px` |

默认中文正文字号为 `16px`，上述普通文字区粗略可容纳每行 35～50 个全角汉字。混排、标点、公式和字体会影响实际字数，不需要手动给正文断行。

## 2. 窗口变窄时的规则

| 窗口宽度 | 布局变化 |
| --- | --- |
| `1280px` 及以上 | 可显示右侧栏；有右侧栏时，当前位置和搜索框分别成框，搜索框与右侧栏对齐 |
| 小于 `1280px` | 右侧栏隐藏，正文获得更多横向空间 |
| `768～1023px` | 左侧预留空间变为 `272px`，侧栏实际宽 `244px`；页面左右留白各 `20px`，正文左右内边距各 `24px` |
| 小于 `768px` | 左侧栏变为菜单抽屉；页面左右留白各 `12px`，正文左右内边距各 `18px` |
| 小于等于 `540px` | 胶片相册入口由两列变为一列 |

正文框和右侧栏可以分别滚动，外框留在原位。调整长度时，不必让文章刚好塞进一屏。

## 3. 新文章与封面

推荐每篇文章使用一个独立目录，把正文和图片放在一起：

```text
content/papers/example/
├── index.md
├── cover.jpg
└── figure-1.png
```

`index.md` 开头写文章信息，两个 `---` 之后是正文：

```yaml
---
title: 文章标题
date: 2026-11-10
type: docs
weight: 1
cover: cover.jpg
draft: false
---
```

| 字段 | 用途 |
| --- | --- |
| `title` | 标题；也会用于导航、更新日志和封面替代文字 |
| `date` | 发布日期 |
| `lastmod` | 修改旧文章时填写的最后更新日期；未填写时默认使用发布日期 |
| `type: docs` | 使用文档类页面模板 |
| `weight` | 同级左侧文章树排序，数值越小越靠前；首页及更新日志不按它排序 |
| `cover` | 首页轮播封面；同目录写文件名即可，也支持 `/images/xxx.jpg` 或完整图床 URL |
| `coverPosition` | 可选，控制首页封面构图位置，如 `"50% 35%"`，默认 `"50% 50%"` |
| `draft` | `true` 为草稿；正常构建不发布草稿 |
| `comments` | 可选，`false` 关闭该页评论 |

`aliases` 和 `coverAlt` 已移除，无须填写。封面的替代文字根据文章标题生成。

`cover: /images/example.jpg` 对应 `static/images/example.jpg`。设置 `cover` 只指定封面，不会自动把图片插入正文。未填写封面时，会尝试提取正文第一张 Markdown／HTML 图片，再没有则使用默认图。

栏目目录为 `mathtech/`（数理技术）、`papers/`（论文阅读）、`travel/`（旅行影集）和 `friends/`（友邻小站）。`index.md` 是普通文章；`_index.md` 是栏目或分组页，两者用途不同。

## 4. 正文图片与文字长度

日常插图使用相对路径，图片与文章同目录：

```markdown
![图片内容说明](figure-1.png)
```

需要明确控制宽度时可以使用 HTML：

```html
<!-- 占正文可用宽度，按原始比例显示 -->
<img src="figure-1.png" alt="图片内容说明"
     style="display:block;width:100%;max-width:100%;height:auto;margin:1.5rem auto;" />

<!-- 较小的插图：占正文宽度的 80%，居中 -->
<img src="figure-1.png" alt="图片内容说明"
     style="display:block;width:80%;max-width:100%;height:auto;margin:1.5rem auto;" />
```

- `100%`、`80%` 都相对于**正文可用宽度**，并非整页或屏幕宽度。正文宽约 `808px` 时，`80%` 大约为 `646px`。
- 正文图片保持 `height:auto`，避免把宽、高同时写死造成变形。需要限制尺寸时，可用 `width:100%;max-width:640px;height:auto`，手机上仍能缩小。
- 横向照片通常用正文宽度的 `100%`；竖向照片可用 `60%～80%`。示意图以能读清标注为准，不必统一比例。
- 若希望高分屏上更清晰，可准备约显示宽度两倍的原图：正文大图通常选择约 `1600px` 宽，图床参数可从 `w=1600` 或 `w=2000` 起调。这里是写作建议，并非网站自动处理规则。
- 导航和首页共用 `title`，建议标题尽量简洁；8～16 个汉字较容易排版。长标题允许换行，避免为了对齐而插入空格或手工换行。
- 宽公式、宽表格宜分行或拆分。文字宽度在不同窗口下会变化，不要按某一张截图精确拼行。

## 5. 首页轮播与胶片相册入口

首页轮播见 [assets/css/journal.css](assets/css/journal.css)，外层宽度由 `navigation.css` 覆盖。

| 项目 | 当前规则 |
| --- | --- |
| 首页每张幻灯片高度 | 桌面 `clamp(440px, 62svh, 700px)`；手机 `clamp(380px, 56svh, 510px)` |
| 首页摄影封面 | `object-fit: cover`，铺满画面，可能裁掉边缘；重要主体尽量留在画面中央 |
| 首页论文／数理封面 | `object-fit: contain`，完整展示；预留标题区高度 `110px`，图片左右另有内边距 |
| 旅行影集总页轮播 | 高度 `clamp(320px, 42vw, 480px)`；手机 `300px` |
| 城市胶片入口 | 默认两列，列间距 `26px`、行间距 `30px`；封面区域比例 `3:2`，使用 `cover` 裁切 |
| 胶片入口较窄窗口 | 小于等于 `1100px` 时列间距 `18px`、行间距 `22px`；小于等于 `540px` 时单列 |
| 胶片入口标题 | 默认 `18px`，较窄窗口 `17px` |

城市页的胶片入口目前手动配置；新增文章后，如需在城市页出现，需要另加一张卡片：

```text
{{< travel-gallery >}}
  {{< travel-album-card
    title="相册标题"
    link="/travel/city/album/"
    image="https://图床地址/cover.jpg"
  >}}
{{< /travel-gallery >}}
```

卡片的 `image` 与文章的 `cover` 是两份独立配置，建议主动使用同一张封面。胶片样式在 [assets/css/travel-gallery.css](assets/css/travel-gallery.css) 中，浅色为中性浅灰、深色为深灰底片。

保留 `travel-gallery` 短代码作为外层，不要直接改成混排 Markdown 的 `<div>` 包裹，避免自动段落标签进入网格后产生空位。

旅行影集总页的轮播、地图地点链接也在 `content/travel/_index.md` 中手动维护。

## 6. 新文章会自动更新哪些地方

| 位置 | 当前规则 |
| --- | --- |
| 栏目左侧文章树 | 根据内容目录自动生成；按 `weight` 排序；草稿和配置了 `sidebar.exclude` 的项目不显示 |
| 首页轮播 | 三个内容栏目中的非草稿普通文章，按 `lastmod` 倒序取最新 `6` 篇 |
| 首页左侧最近更新 | 同样取最新 `6` 篇普通文章 |
| 右侧更新日志 | 三个内容栏目中的非草稿普通文章，以及有正文但无子页面的相册分组页，按 `lastmod` 倒序取最新 `12` 篇 |
| 城市胶片入口、影集总页轮播、地图链接 | 目前手动配置 |

右侧更新日志显示在首页、有子页面的内容栏目页和友邻小站页；普通数理／论文文章保留阅读目录。旅行内容的普通文章目录目前隐藏。

**只修改正文，不会自动更新 `lastmod`。** 需要让旧文章回到最近更新的前面时，手动填写新的 `lastmod`。日志只显示每篇文章最近一次已知日期，不保存历次修改记录。

用 `_index.md` 建立的独立相册分组页目前可进入右侧更新日志，但不会进入只收录普通文章的首页轮播；希望进入首页的新相册推荐使用独立目录加 `index.md`。

## 7. 调整时去哪里修改

| 想改什么 | 文件与定位关键词 |
| --- | --- |
| 全站宽、左侧栏宽、顶栏高、外框圆角 | `assets/css/navigation.css` 开头的 `--site-shell-width`、`--site-sidebar-width`、`--site-header-height`、`--site-radius` |
| 正文最大宽度和内边距 | 同文件的 `.toudens-page article > main`；旅行页还看 `.toudens-workspace-travel` |
| 右侧栏宽度 | 同文件的 `.hextra-toc`、`.toudens-timeline`，以及桌面顶栏 `grid-template-columns` 中的 `264px`，需要一起修改 |
| 首页外框、轮播最大宽度 | 同文件的 `.journal-home`、`.journal-feature` |
| 首页图片高度、标题字号、玻璃标题区 | `assets/css/journal.css` 的 `.journal-slide`、`.journal-caption`；同时检查 `navigation.css` 是否有覆盖 |
| 胶片齿孔、底色、图片比例、标题大小 | `assets/css/travel-gallery.css` |
| 首页选哪些文章、显示几篇 | `layouts/magazine-home.html` |
| 更新日志文章范围、数量、日期显示 | `layouts/_partials/journal/timeline.html` |
| 左侧文章树、首页左侧最近更新 | `layouts/_partials/journal/sidebar.html`、`tree.html` |
| 封面路径及默认图规则 | `layouts/_partials/journal/cover.html` |
| 顶栏搜索与当前位置结构 | `layouts/_partials/navbar.html`；样式在 `navigation.css` |
| 四个栏目名称和站名 | `hugo.toml`，栏目标题还需同步各栏目 `_index.md`，首页和更新日志中的栏目标签也有对应映射 |

`navigation.css` 在 `journal.css` 之后加载，胶片页的 `travel-gallery.css` 又在它之后加载；查看最终样式时注意覆盖顺序。正文仍使用主题样式，不要直接编辑 Hugo 模块缓存或 `public/` 下的构建产物。

修改布局、配色时同时照顾浅色、深色和窄屏。颜色优先使用 `--site-panel`、`--site-ink`、`--site-muted`、`--site-line` 等变量；胶片使用自己的 `--film-*` 变量。

## 8. 预览与发布

在项目根目录运行 `hugo serve` 可本地预览，地址以终端实际输出为准；当前常用地址是 `http://localhost:1313/`。大幅修改模板后若浏览器还显示旧结构，先完整刷新页面。

线上使用 `.github/workflows/hugo.yml` 构建并发布；推送到 `main` 或 `master` 后触发。文章、导航和搜索索引都在构建时生成，新内容需要随站点重新构建发布。
