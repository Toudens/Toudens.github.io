### 二、我国武装力量组成

我国武装力量组成：中国人民解放军现役部队和预备役部队，中国人民武装警察部队、民兵。
* **中国人民解放军现役部队**：由陆军、空军、海军、第二炮兵组成。
* **人民武装警察部队**：分为内卫部队、列入武警序列由公安部门管理的部队、列入武警序列受国务院有关部门和武警双重领导的部队。
* **民兵**：分为基干民兵和普通民兵。

### 三、武器制导系统
#### 3.1 基本概念

* **直接命中**：指制导武器的圆概率误差小于该武器弹头的杀伤半径。
* **圆公算偏差**：以目标中心为圆心，画一个包含 50% 弹着点的圆，该圆半径为圆公算偏差。
#### 3.2 自主制导

指挥制导导弹飞行的导引信号不依赖于目标或制导站，仅由导弹本身安装的测量仪器测量地球或宇宙空间的物理特性决定导弹的飞行轨迹，用于攻击固定目标。
* 惯性制导多用于复合制导中初段、中段制导，地地中程导弹、洲际导弹、潜地导弹。
* 地形匹配制导不需连续使用，只需选择若干定位区，不用于末端制导。
* 景象匹配制导只用于末端制导。

| 制导方式    | 优点                                       | 缺点       |
| :------ | :--------------------------------------- | :------- |
| 惯性制导    | 不易受外界干扰，不受距离限制、可全天候作战、<br>可同时发射的导弹数量不受限制 | 积累误差精度不高 |
| 地形匹配制导  | 地形越复杂制导精度越高                              | 不适用于平原海面 |
| 景象匹配制导  | 适用于地势平坦的地方                               |          |
| GPS卫星制导 | 可以取消地形匹配制导、缩短制定攻击计划时间、<br>无累计误差          | 易受电子干扰   |

#### 3.3 遥控制导
遥控制导导弹受控于制导站，飞行轨迹可以根据目标运动情况而随时改变，适用于攻击活动目标，在地空、空地、空空和反坦克导弹上使用较多，分为指令制导和波束制导，要求同时定位目标和导弹。

| 制导方式               | 优点                         | 缺点                                |
| ------------------ | -------------------------- | --------------------------------- |
| 有线电指令制导<br>（手控）    | 设备简单、不易受干扰                 | 训练射手困难、导弹飞行速度较低、<br>受地形限制大、射击死区较大 |
| 有线电指令制导<br>（红外半自动） | 操作简便、命中率较高<br>攻击的死区较小      | 受导线的限制，设备比较庞大                     |
| 无线电指令制导            | 作用距离远、制导精度高                | 容易受干扰                             |
| 电视指令制导             | 观察直观、多目标针对性                | 易受天气影响、抗干扰性差、作用距离不大               |
| 雷达波束制导             |                            | 容易脱离波束、易受无线电干扰                    |
| 激光波束制导             | 设备简单、对方难以干扰<br>工作可靠、宜反坦克导弹 | 击中目标前激光发射器不能停止工作                  |

#### 3.4 自动寻的制导系统
自动寻的制导一般用于末端制导。

| 制导方式       | 特点                         |
| ---------- | -------------------------- |
| 主动式自动寻的制导  | 由导弹主动向目标发射能量，并接收从目标反射回来的能量 |
| 半主动式自动寻的制导 | 能量发自设在地面、军舰或飞机制导站，导弹被动感受能量 |
| 被动式自动寻的制导  | 能量发自目标，导弹被动感受能量            |

| 制导方式      | 优点                                 | 缺点                               |
| --------- | ---------------------------------- | -------------------------------- |
| 雷达自动寻的制导  | 全天候、全向攻击、制导距离比较远                   | 易受电子干扰、结构复杂<br>重量、尺寸大、成本高        |
| 红外线自动寻的制导 | 分辨力高、抗干扰能力较强、设备简单<br>重量轻、尺寸小、隐蔽性较好 | 易受云雾等天气影响<br>不具备敌我识别能力<br>制导距离较近 |
| 电视自动寻的制导  |                                    |                                  |
| 毫米波自动寻的制导 | 受气象和烟尘的影响小、制导精度较低                  | 受大雨影响大<br>制导距离较近<br>抗干扰能力较强      |
| 激光自动寻的    | 抗干扰能力强、成本低体积小<br>活动固定目标都可攻击、精度极高   | 受气候、烟尘影响大<br>制导距离较近              |

#### 3.5 复合制导
* **优点**：克服单一制导带来的缺陷，制导距离远，精度高，抗干扰能力强。
* **缺点**：结构较为复杂，成本高。

### 四、导弹基础知识
导弹是一种具有动力装置、制导系统、战斗部的飞行武器。有一段在大气层中飞行。
* **战斗部**：常规战斗部、特种战斗部。
* **发动机**：火箭发动机、涡喷、涡扇、冲压发动机。液体火箭发动机，固体火箭发动机。涡轮喷气发动机，冲压喷气发动机（必须有较高初始速度才能工作）。
* **制导系统**：见上方各表。

【注】制导炸弹、制导炮弹、制导鱼雷、制导地雷不属于导弹，但火箭助飞鱼雷属于导弹。

#### 4.1 导弹分类
**按作战任务的性质分为：**
* **战略导弹**：执行战略任务、打击战略目标。
* **战役导弹**：打击战役纵深内重要目标。
* **战术导弹**：直接支援部队战斗行动。

**按发射点与目标的关系位置分为（后面的“地”一定是指地面的固定目标）：**
* **从地面发射**：**地地**、地空、地舰、地潜。
* **从空中发射**：空空、**空地**、空舰、空潜。
* **从水面发射**：舰舰、**舰地**、舰空、舰潜。
* **从水下发射**：潜潜、**潜地**、潜空、潜舰。

**按攻击目标分类：**\
反坦克、防空、反潜、反辐射（针对被动式的雷达自动寻的制导和波束制导）。

#### 4.2 导弹战斗部与毁伤评估
* **爆破型**：炸药爆炸高温高压形成冲击波。
* **破片型**：具有一定动能和分布密度的破片打击目标。
* **聚能破甲型**：利用炸药聚能效应击穿装甲。
* **贫铀弹**：高密度高强度高韧性的贫铀合金制成。

**毁伤能力评估：**
* **对面目标**：使用等效百万吨当量衡量核武器毁伤能力，与命中精度基本无关。
* **对点目标**：主要取决于命中精度、而不仅取决于弹头当量和数量。
$$
点毁伤率=弹头数量\times(弹头当量)^{2/3}/(导弹精度)^2
$$

**多弹头技术：**
* **集束式**：智能攻击单一目标。
* **分导式**：每个子弹头没有独立的制导系统，由母弹头一个个释放制导。
* **全导式**：每个子弹头均有独立的制导系统。

【注】引信分为触发引信、非触发引信（近炸引信）。

#### 4.3 导弹导引方法

即以怎样的方式接近目标：
* **纯追踪**：速度向量每时每刻都指向目标，固定或活动目标（目标速度不是很快）。
* **比例接近**：速度向量的转动角速度正比于目标视线转动角速度，多用于自动导引（各种场合都比较实用，实现比较复杂，适用于快速机动的目标）。
* **三点法**：导弹、目标和制导站始终在一条直线上。
* **方案飞行**：发射前预定飞行轨迹。

### 六、电子对抗技术

水声对抗、射频对抗（电子侦察/反侦察，电子干扰/反干扰，火力摧毁/反摧毁）、光电对抗。

#### 6.1 无线电对抗
波长越长带宽越短，通讯范围更广，设备更加庞大。

**无线电通信侦察：**
* **通信情报侦察**：侦听敌方通信和指挥联络信号，查明无线电设备类型间接获得敌军配置。
* **通信技术侦察**：查明敌方无线电通信设备技术性能，侦察距离远，快速隐蔽，易受欺骗。

**无线电通信干扰：**
* **压制式干扰**：分为瞄准式（敌短波）、阻塞式（敌超短波）、半瞄准式（扫描）。条件为频率对准、干扰功率超过被干扰信号功率、调制方式合适。
* **欺骗式干扰**。

**无线电通信反侦察：**
控制无线电发射的时机、方向、范围、快速电报通信、保密通信、不容易被侦收通信体制（如激光、微波接力通信）、设置假电台。

**无线电通信反干扰：**
* 提高收信端信号强度（提高功率、设置中继站）。
* 采用抗干扰能力强的通信方式（数字保密、对流层扩射通信）。
* 采用扩频技术（宽频带通信等，直序列式和跳频式）。

【注】利用无线电静默不能用于对付敌人的无线电通信干扰。无源干扰使用器件本身的物理特性来干扰无线电通信（如密闭的金属外壳）。对无线电通信的干扰只可以为有源干扰，不是全封闭则无源干扰失效。

#### 6.2 雷达对抗
发射探测脉冲和接受被照射目标的回波发现目标。

**雷达侦察**：作用距离远、获取多目标、预警时间长、隐蔽性好、只测向不测距。\
**雷达干扰**：利用雷达设备发射干扰波，利用能反射或能衰减无线电波的器材反射。
* **有意干扰**：积极干扰（压制性、欺骗性）、消极干扰（压制性、欺骗性）。
* **无意干扰**：反射型器材、吸收型器材、隐身技术。

**雷达反侦察：**
* 控制雷达开机时间和工作频率使用、隐蔽雷达和新式雷达启用必须经过批准。
* 更换可能被敌侦悉的雷达阵地、 设置假雷达，发射假雷达信号。

**雷达反干扰：**
* 增大发射功率或增大脉冲宽度，改变、扩展雷达工作频率。
* 采用隐蔽扫描、提高雷达天线方向性、采用动目标显示。

### 七、夜视与反夜视技术
极远红外在军事上基本没有应用，极少使用近红外（设备几乎不发射这一波段）。

#### 7.1 夜视技术与器材
**主动式红外夜视仪：**
* 发展较成熟、造价低廉，观察效果较好，可观测红外光源，具有一定的识别伪装能力。
* 容易暴露。

**微光夜视仪：**
* 被动工作方式不易暴露观察距离能较远，体积小重量轻。
* 受云雾星月光等自然条件影响大，识别伪装的能力弱。

**微光电视：**
* 图像清晰，视距远，可实现远距离传送和遥控摄像。
* 耗电多，体积重量大，操作维护复杂，受自然环境条件的影响较大。

**热像仪：**
* 不易被对方发现干扰、全天候观察作用距离远，具有较好的识别伪装的能力。
* 图像不够清晰，分辨细节的能力较弱，体积重量大，结构复杂成本高。

#### 7.2 反夜视技术

**热红外伪装技术：**
* 模拟植物背景全天温度变化或热红外特征的热红外伪装网。
* 单兵热伪装器材。
* 红外烟幕剂、涂层材料等。
* 全波段伪装。

**假目标技术：**
* 模拟目标外形表面散射和辐射特征，模拟武器射击的闪光、气浪、运动等特征。
* 法阵内装式热红外隐身技术。

**对付夜视器材的基本方法：**\
利用遮障和地形地物、利用复杂的气象条件、消除反差、消除温差、机动规避、实施干扰、火力摧毁。
