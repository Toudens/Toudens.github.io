### 逻辑门与布尔代数

#### 二进制与基本门
数字逻辑的基础是二进制变量（1/0，True/False，On/Off）以及三大基本操作：
*   **与 (AND)**：$X \cdot Y$ 或 $XY$，仅当全为1时输出1。
*   **或 (OR)**：$X + Y$，只要有1则输出1。
*   **非 (NOT)**：$\bar{X}$ 或 $X'$ 或 $\sim X$，取反。

#### CMOS开关模型
现代晶体管门电路（CMOS）可抽象为开关模型：]

| 晶体管类型 | 符号与模型 | 导通条件 | 串并联逻辑 |
| :--- | :--- | :--- | :--- |
| **n-Channel** | 常开 (NO) 开关 | Gate = 1 (高电平) | **串联**实现 AND 逻辑 |
| **p-Channel** | 常闭 (NC) 开关 | Gate = 0 (低电平) | **并联**实现 OR 逻辑 |

#### 布尔代数核心定律
布尔代数用于规范和转换逻辑函数，除了交换律、结合律、分配律外，核心定理包括：
*   **恒等与零一律**：$X + 0 = X, X \cdot 1 = X$ ； $X + 1 = 1, X \cdot 0 = 0$
*   **幂等律与还原律**：$X + X = X$ ； $\overline{\overline{X}} = X$
*   **吸收律 (Absorption)**：$X + X \cdot Y = X$ ； $X \cdot (X + Y) = X$
*   **化简律 (Simplification)**：$X + \bar{X} \cdot Y = X + Y$
*   **一致律 (Consensus)**：$XY + \bar{X}Z + YZ = XY + \bar{X}Z$ （用于消除多余项）
*   **德摩根定律 (DeMorgan's)**：$\overline{X + Y} = \bar{X} \cdot \bar{y}$ ； $\overline{X \cdot Y} = \bar{X} + \bar{Y}$

> [!Note] 
> **对偶原则 (Duality)**：将表达式中的 `+` 和 `·` 互换，`0` 和 `1` 互换，即可得到对偶式。注意：除非是自对偶函数，否则函数的对偶式**不等于**原函数本身。

#### 规范形式与标准形式
*   **最小项 (Minterm, $m_i$)**：包含所有变量的 AND 项。$n$ 个变量有 $2^n$ 个最小项。
*   **最大项 (Maxterm, $M_i$)**：包含所有变量的 OR 项。
*   **转换关系**：$M_i = \overline{m_i}$ （最大项是对应最小项的补码）。

> [!Note] 
> **表示法转换**：任何函数都可表示为最小项之和（SOM，如 $\Sigma m(1,4,5)$）或最大项之积（POM，如 $\Pi M(0,2,3,6,7)$）。
> **求补函数**：若 $F = \Sigma m(1,3,5,7)$，则其补集 $\bar{F} = \Sigma m(0,2,4,6)$，也等价于 $\Pi M(1,3,5,7)$。
### 电路优化与卡诺图

#### 成本评估标准
优化算法需要具体指标来衡量电路简单程度：
1.  **字面量成本 (L)**：变量及其补码在表达式中出现的总次数（代表 AND 门输入数）。
2.  **门输入成本 (G)**：$G = L +$ (多变量乘积项的数量)。用于衡量所有 AND/OR 门输入总数。
3.  **含非门输入成本 (GN)**：$GN = G +$ (需要取反的独立单变量数)。

#### 卡诺图 (K-Map)
真值表的拓扑变形（格雷码排列：00, 01, 11, 10），用于图形化识别相邻项。
*   **相邻规则**：相邻方格的变量仅有一位不同。3变量卡诺图是**圆柱体**拓扑（左右相连），4变量卡诺图是**甜甜圈/环面**拓扑（上下、左右均相连）。
*   **合并规则**：将相邻的 `1` 圈成 $2^k$ (1, 2, 4, 8, 16) 个格子的矩形。圈越大，消去的变量越多。

#### 优化算法与无关项
1.  **素蕴含项 (PI)**：无法再被包围进更大矩形的极小化乘积项。
2.  **基本素蕴含项 (EPI)**：**独占**某个最小项的 PI。
3.  **选择规则**：首先必须包含所有 EPI；然后以最小的重叠代价（最小成本）选择剩下的 PI，直到覆盖所有的 `1`。

> [!Note] 
> **无关项 (Don't Cares, X)**：某些输入组合在实际系统中永远不会发生（如 BCD 码中的 10~15）。在卡诺图中，`X` 可以根据需要灵活当作 `1` 或 `0` 来放大矩形圈，从而极大降低电路成本。

#### 多级电路优化
当两级逻辑（SOP/POS）优化到极限后，可通过**代数提取公因式 (Factoring)** 进一步降低门输入成本(G)。
*   例：$F = \bar{A}\bar{C}\bar{D} + \bar{A}B\bar{C} + ABC + AC\bar{D}$ (G=16)
*   提取后：$F = (\bar{A}\bar{C} + AC)(B + \bar{D})$ (G=10，成本显著下降！)

### 附加门与电路参数

#### 集成电路与参数
*   **集成度**：SSI (<10门), MSI (10-100门), LSI (100-千级), VLSI (千级至数亿门)。
*   **扇入 (Fan-in)**：逻辑门允许的最大输入端数。
*   **扇出 (Fan-out)**：逻辑门输出能驱动的“标准负载”最大数量。负载过大会导致电平转换时间超标。
*   **噪声容限 (Noise Margin)**：能容忍的最大外部叠加噪声电压。

#### 延迟模型 (Delay Models)
真实电路状态改变需要时间 $t_{pd}$。

| 模型 | 定义与特性 | 适用场景 |
| :--- | :--- | :--- |
| **传输延迟 (Transport)** | 输入改变后，输出经过固定延迟 $t_{pd}$ 后绝对改变。 | 理想化时间平移计算 |
| **惯性延迟 (Inertial)** | 引入**拒绝时间 (Rejection time)**。如果输入脉冲比拒绝时间短，输出将**不发生变化**。 | 模拟真实物理电路，用于**过滤毛刺 (Glitch)** 和窄脉冲 |

> [!Note] 
> **传播延迟公式**：$t_{pd} = \max(t_{PHL}, t_{PLH})$。
> 实际延迟受扇出影响极大，例如：$t_{pd} = 0.07 + 0.021 \times SL$ (SL为驱动的标准负载数)。

#### 通用门与复杂门
*   **缓冲器 (Buffer)**：逻辑上 $F=X$，物理上用作**电子放大器**，提升电压和驱动能力。
*   **NAND (与非) / NOR (或非)**：
    *   NAND 既是 AND-Invert，也可由德摩根定律变形为 Invert-OR。
    *   由于 CMOS 原理，NAND/NOR 的面积和速度优于 AND/OR。
    *   它们是**通用门 (Universal Gates)**，可独立实现所有布尔代数。

#### 异或 (XOR) 与同或 (XNOR)
*   **异或 ($X \oplus Y$)**：相异为1，即 $X\bar{Y} + \bar{X}Y$。
*   **同或 ($X \equiv Y$)**：相同为1（等价），即 $XY + \bar{X}\bar{Y}$。
*   **多变量特性**：对于3个及以上变量，$\oplus$ 严格意义上称为**模2和 (Mod 2 sum)** 或 **奇函数**（当输入中 `1` 的个数为奇数时输出1）。卡诺图上呈“棋盘”状分布。
*   **典型应用**：奇偶校验生成器与检测器 (Parity Generators/Checkers)、加法器、计数器。

#### 三态门 (3-State Logic)
传统门的输出只有 0 和 1，严禁将两个门的输出短接。三态门引入了控制端 `EN`。
*   **高阻态 (Hi-Z)**：当 `EN = 0` 时，输出呈现 Hi-Z，相当于**物理断开 (Open Circuit)**。
*   **总线规则**：允许多个三态门的输出连接到同一根导线 (OUT) 上。**但前提是**：任意时刻，最多只能有一个门的 `EN = 1`，其余门必须全部处于 `Hi-Z` 状态，否则会引发短路冲突。
*   **典型应用**：数据选择器 (Multiplexer)、CPU 数据总线。
